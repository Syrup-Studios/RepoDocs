# Privacy policy

This website serves static documentation generated from public Git repositories. It does not run user accounts, track users across sites, or sell personal data.

## Information this site collects

This site does not collect personal information itself. The pages are static HTML files. There is no login, no comment system, and no analytics account owned by this site.

When you open a page, the hosting provider may record standard server logs. These logs can include your IP address, the page you requested, the browser you used, and the time of the request. The hosting provider owns and controls these logs. See the hosting provider's privacy policy for details.

## Links to other sites

Documentation pages can link to public repositories and external services such as GitHub. This site does not control those services. Their privacy policies apply when you visit them.

## Cookies

This site does not set cookies for its own purposes. External services linked from the pages may set their own cookies.

## Contact

For privacy questions about this site, open an issue in the source repository linked in the site header.
